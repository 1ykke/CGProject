# 基于软件光栅化的交互式太阳系可视化与抗锯齿分析

## 当前开发状态

当前默认项目是固定的太阳、八大行星。使用逐星球面图作为不可变基准；九颗天体都有可调的三维网格起伏和重新计算的法线。地球和火星使用相对高度图，其他天体从各自影像生成固定的艺术化形状图。水星现在可单独调整影像锚定的撞击坑深度；金星用独立的雷达表面与半透明可见云顶网格，可分别调整两层起伏；木星可单独调整云带及大红斑区域的云顶形状。单星设计页还支持在球面上用 Raise、Lower、Smooth 笔刷局部雕刻；金星可选择云顶或雷达表面，笔画可撤销，编辑网格随项目保存。用户可在桌面端逐星进入放大设计视图，调整参数、对照原貌、重置本星，返回总览后运行 REBOUND 引力与碰撞模拟。旧的 `examples/encounter.json` 和 `examples/collision.json` 仍作为独立实验沙盒读取。

当前渲染器由 CPU 对球体和环带三角形进行近裁剪、透视投影、深度测试、底图采样与 1× 单采样、4× SSAA、4× MSAA。轨道线段也会在投影前裁到相机近端。MSAA 保留四个覆盖及深度样本，每个三角形在同一像素内复用一次着色结果；像素显微镜显示最终样本位置、天体与表面类别、深度、线性颜色及合成 RGB。旧实验沙盒仍使用程序化材质。Dear ImGui 桌面窗口负责逐星设计、旋转相机、同场景采样对比和启动同一套 REBOUND 模拟；OpenGL（Linux/Windows）或 Metal（macOS）只上传并显示 CPU 图像。桌面 Pixel 页显示当前帧每侧的着色次数及自动测量的 CPU 渲染耗时中位数；完整阶段性能统计仍是后续阶段。

**当前边界：**九颗天体使用不同球面图并提供对应的参数：太阳颗粒/黑子，水星撞击坑形状与对比，金星双层云顶/雷达表面，地球地形/云/冰，火星地形/沙尘，木星云带与大红斑局部形状，海王星风暴形状与位置，土星环及卡西尼缝，天王星轴倾与淡环。九颗天体的整体起伏滑块都会改变网格轮廓；太阳与气态行星的形状仅为影像引导的艺术化光球或云顶，并非固体山脉或物理高程。水星坑深和金星雷达表面起伏同样是影像推断的视觉效果，不是测量高程。天气流体演化、多次散射和科学高程仍待扩展。轨道距离是示意值，不用于精密天文预测。素材来源和授权见 `docs/ASSET_SOURCES.md`。

行星光照采用克制的大气薄边、较暗的夜面和与地形一致的细节法线。地球有受光云层、可调高度与地表云影，以及海面的视角相关高光；土星有本体投向环带、环带投向本体的阴影，环倾角同时改变几何和投影。设计近景使用统一的摄影主光，包含太阳的模拟快照按太阳方向受光。水星没有大气，太阳保持自发光；金星的散射与云顶合成一次，避免透明度重复叠加。

设计面板的 `Light and atmosphere` 可调细节强度、大气密度，地球还可调 `Cloud altitude` 和 `Cloud shadow`。四颗气态／冰巨星有 `Cloud flow and storms` 云带扭曲；木星和海王星可用经纬度、尺寸与长宽比改变原有风暴，颜色与三维起伏同步变形，附近云带也会随之改变。经度用度数表示，纬度以北为正。笔刷仍使用原来的球面坐标。这些参数支持撤销、重做、重置、正式保存和草稿恢复；旧项目缺省参数自动补齐。算法与范围见 `docs/PLANET_RENDERING.md`。

本轮行星外观改动已完成 WSL/Linux Release 构建、六组自动测试、逐星同视角对照和实际 OpenGL 编辑流程检查；原生 Windows 与 macOS 尚未复测。细节与散射增加了高质量近景的 CPU 渲染开销，交互仍使用后台低分辨率预览；全景中很小的行星省略不可见的细节法线计算。

### 构建与运行

需要 CMake 3.21+、C++17 编译器和网络访问以获取 nlohmann/json 与 REBOUND 5.0.1。也可用 `-DREBOUND_SOURCE_DIR=/path/to/rebound` 指向兼容的 REBOUND 5.0.1 源码目录。

```sh
cmake -S . -B build-headless -DPLANET_BUILD_DESKTOP=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build build-headless -j
ctest --test-dir build-headless --output-on-failure
./build-headless/planet_sandbox --output solar-system.ppm --state state.json
./build-headless/planet_sandbox --body earth --output earth.ppm
./build-headless/planet_sandbox --body mars --output mars.ppm
./build-headless/planet_sandbox --config examples/encounter.json --time 0 --output frame.ppm
./build-headless/planet_sandbox --config examples/collision.json --time 0.3 --output collision.ppm --state collision-state.json
./build-headless/planet_sandbox --config examples/encounter.json --time 0.3 --samples 4 --output ssaa4.ppm
./build-headless/planet_sandbox --body earth --sampling msaa4 --output earth-msaa4.ppm
```

PPM 可用系统图片工具转换为 PNG。`--sampling` 接受 `single`、`ssaa4` 或 `msaa4`；兼容选项 `--samples 1|4` 分别对应单采样和 4× SSAA。同一次调用请只使用一种采样选项。不提供 `--config` 时使用固定太阳系；`--body earth` 等选项导出单星近景。质量、长度和时间是无量纲模拟单位；显示半径和 `display_scale` 不改变引力与碰撞半径。旧实验沙盒仍支持通用 `appearance` 字段。REBOUND 使用 GPL-3.0，发布链接后的程序前需核对项目许可证与第三方声明。

### 离线抗锯齿实验

```sh
./build-headless/planet_aa_benchmark --output-dir build-headless/aa-run-001
./build-headless/planet_aa_benchmark --config my-solar-system.json --output-dir build-headless/my-aa-run-001 --width 256 --height 192
```

正式实验使用 Release。CLI 默认每个场景和方法预热 3 次、测量 11 次，可通过 `--warmup` 和 `--runs` 调整。`metrics.csv` 的 `render_ms` 为 CPU 渲染中位数，`render_p95_ms` 使用最近秩法，`timings.csv` 保存每次正式采样。已有 PNG、参考图、边缘掩码和项目 JSON 一并保留。计时采用渲染器内部时钟，范围与 Pixel 页一致。跨机器对照时，随结果记录提交号、系统、CPU、编译器及 Release 配置。


实验固定地球轮廓、土星环边缘和细轨道线，逐场景对同一快照与相机生成 `single`、`ssaa4`、`msaa4` 和离线 `ssaa16` PNG。每个场景另有 `_edges.png`，白色部分是参考图逐样本几何边缘及其一像素邻域；同一星球的云层与地表按同一几何归属计。`metrics.csv` 的 `edge_mae_linear` 与 `full_mae_linear` 是显示图像解码回 gamma 2.2 线性空间后的平均 RGB 绝对误差；`shade_evaluations` 只统计片元着色，细轨道线为零。每种模式先进行一次不计时预热；`render_ms` 仅计随后一次 CPU 渲染，不含 PNG 写入，适合观察本机趋势，不作为严格性能基准。输出中的 `project.json` 保存本次 DIY 参数。输出路径必须是尚不存在的新目录，全部文件写完后才发布，以免失败重跑混入旧结果。16× 仅用于离线近似参考，不进入桌面实时采样菜单。PNG 使用随项目附带的 `stb_image_write`（Public Domain / MIT）。

### 桌面编辑器

桌面版需要 GLFW 和系统图形开发环境；首次配置会下载 Dear ImGui。Linux 需要 OpenGL 开发包，macOS 需要 Xcode 命令行工具和 Metal。桌面目标默认关闭，可单独启用：

```sh
cmake -S . -B build-studio -DPLANET_BUILD_DESKTOP=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build-studio -j
./build-studio/planet_studio
```

不传项目路径时优先打开默认保存文件，不存在时新建固定太阳系；保存路径默认 `my-solar-system.json`；传入旧 JSON 可继续使用实验沙盒。点击画面中的行星、左侧目录项或 `Design selected`，镜头会平滑飞入该星球近景；右侧只显示当前星球已实现的设计参数，`Show baseline` 临时预览默认外观（不撤销自己的修改），预览期间外观编辑控件禁用，取消勾选即可恢复设计与编辑；`Reset this body` 则会真正重置该星球的设计。再用 `Back to system` 平滑返回全景。在近景中左键拖动画笔修改局部形状，右键拖动旋转视角；左侧 `Undo` 撤销最近的一次参数修改或雕刻，`Redo` 可恢复。`Orbit / Physics` 独立编辑质量、碰撞半径、位置和速度。左侧 `Demo presets` 下拉菜单按 `Appearance & AA` 和 `Motion & collisions` 分组，提供地球地形、土星环边缘和地球与火星碰撞三个一键演示；碰撞演示只对临时地球与火星副本运行 REBOUND，保留当前 DIY 外观，`Play/Pause`、`Step`、`Reset` 只控制演示，`Exit demo` 恢复进入前的选择与视角。演示中 `Save` 仍保存原 DIY 项目，不会写入演示轨道。`Run simulation` 会从设计近景平滑拉远到九体全貌，镜头到达后才开始推进 REBOUND 时间；从模拟返回设计也先冻结画面并拉远。模拟画面中的 `Time` 可暂停并跳到指定时刻，`Reference orbit` 将所选行星的固定目录轨道与当前 DIY 轨道并排标示，碰撞事件可点击回放。参考轨道只用于对照，不改变保存的设计或物理参数。碰撞后较大质量天体继承可见身份，同质量按固定目录顺序。模拟重置恢复九个设计入口。左侧 `Save`/`Load` 控制项目 JSON；窗口操作不会自动改写源文件。场景可拖拽旋转、滚轮缩放；顶部可选择 `1x`、`4x SSAA` 或 `4x MSAA`。勾选 `Inspect` 后点击画面，右侧 `Pixel` 页显示所选像素的最近邻放大图；直接进入 `Pixel` 页也会自动开启取样。手动关闭 `Inspect` 或使用 `Reset view` 后，检查模式保持关闭，Pixel 页会提示重新开启 Inspect，停留在该页时点击画面不会雕刻地形；正常雕刻需返回 Design 页并关闭 Inspect／Compare。勾选 `Compare` 可在同一场景快照下并排设置左右采样模式，并自动启用像素检查、打开 Pixel 页；此时隐藏重复的 Inspect 开关，并暂停模拟／碰撞演示；比较期间 `Play` 禁用，退出比较后可重新播放，`Step`、`Reset` 和模拟时间轴仍可用于选择快照。点击任一栏会同步显示左右同一局部位置的取样框和放大图，`Region` 可选择 9×9、17×17、25×25 个原始像素；边缘选区会整体移回各自画面内，避免跨越比较分隔线。选中画面后可用方向键微调，右键拖动旋转。`Frame cost` 只保留 `Method`、`Shades`、`Time (ms)` 三列，以及 `Time (ms): median of 11 renders (CPU only)` 说明；说明随面板宽度自动换行，没有测量按钮。进入 Compare、Inspect 或 Pixel 页后，在画面停止变化 0.25 秒时自动开始：每种方法预热 3 次、测量 11 次，左右交替先后顺序，完成后固定显示中位数。计时只统计 CPU 渲染，不含像素诊断提取、图像上传、比较拼接及界面绘制；测量生成的画面直接用于显示，不再额外渲染一遍。结果完成后复用静止画面，界面保持响应，只有画面或取样像素变化才重绘；未改变图像时也不重复上传纹理。修改外观、视角、场景、分辨率或采样方法时立即清空旧计时，等操作停下后自动重测；连续拖动时推迟测量。移动取样框只刷新像素诊断，改变 Region 只调整放大范围，两者均保留有效计时。单视图模拟／碰撞播放期间暂不测量，暂停后自动测量，继续播放会清空旧结果；Compare 仍按原行为暂停播放。测量期间显示简短进度，结果适合本机演示比较，仍会受系统负载影响。`Details` 默认折叠，保留局部像素坐标、左右最终 RGB 和所点击一侧的样本诊断。比较时隐藏碰撞列表，退出比较后可在模拟面板查看。切换地球／土星预设保留当前比较方法，碰撞预设退出比较并启动演示。检查或对比期间暂停局部雕刻；镜头过渡期间暂停雕刻和画面选择，结束后恢复所选采样模式。

桌面端在后台执行 CPU 渲染，界面可继续响应鼠标和控件操作。拖动相机、调整参数、雕刻、播放模拟或镜头过渡时，普通视图临时使用宽高各减半的单采样预览；停止操作约 0.18 秒后提交原分辨率与所选采样质量的画面，恢复时间还包括等待当前渲染完成。后台最多保留一个正在处理的画面和一个最新待处理画面，持续拖动时也会展示已经完成的预览。新视角尚未显示时，暂缓画面内选点与雕刻，防止旧画面导致误操作；相机和界面控件仍可使用。Compare、Inspect 和 Pixel 页始终使用固定分析分辨率及采样设置，移动取样框保留有效计时，实际场景变化才重新测量。

从一颗行星近景直接选择另一颗行星时，镜头先经过太阳系全景，再飞入新星球，避免在星际空白处横移。镜头过渡约 0.9 秒，跨行星过渡约 1.5 秒；动画按经过时间推进，可见画面的更新频率仍取决于 CPU 渲染速度。

DIY 编辑现在共享一套撤销与重做记录：参数拖动、物理参数、局部雕刻和重置按操作顺序记录，一次拖动或笔画算一步。左侧 `Undo` / `Redo` 的提示显示即将恢复的操作；快捷键为 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 或 Ctrl+Y，输入文字时保留输入框自己的撤销行为。切换行星不会清空历史，撤销跨星球修改会选中受影响的行星。模拟、镜头过渡、碰撞演示和原貌预览期间暂不编辑历史。记录最多保留 48 步，序列化快照合计最多 32 MiB，超限时移除最早记录；关闭应用后不保留撤销栈。

左侧显示 `Unsaved changes` 或 `No unsaved changes`；撤销回保存内容也会清除未保存标记。正式项目仍由 `Save` 更新，写入完整临时文件成功后再替换目标；保存失败会保留未保存状态。停止修改约一秒后在项目旁写入 `<项目文件>.recovery.json` 恢复草稿，持续操作时约每五秒保存一次；正常关闭会等待最新草稿写完。草稿只保存 DIY 项目，不保存临时碰撞场景或模拟进度。启动时可选择 `Restore draft` 或 `Discard draft`，恢复后仍须 `Save` 才会更新正式文件。如果正式文件后来被修改、损坏或缺失，存在有效草稿时仍可启动恢复，界面会说明冲突；损坏的草稿会保留并提示，可明确丢弃后恢复自动写入。加载时若有未保存修改，会先提示确认；加载其他项目会为离开的项目保留恢复草稿。未传路径时优先打开已存在的 `my-solar-system.json`。恢复草稿与临时文件已排除在 Git 上传之外。

本轮后台预览与编辑恢复改动在 WSL/Linux OpenGL 环境完成 Release 构建和自动测试；Metal 前端同步接入了同一流程，尚未在本轮复测 macOS 或原生 Windows。

设计与模拟现在使用不同的面板重点：全景中选择行星或其名称标签，镜头会飞入近景；右侧显示行星名称、原貌参数和可折叠的 `Sculpt brush`。全景右侧的 `Design <行星名>` 也可进入设计。局部笔刷仅在 Design 页生效，Orbit / Physics 和 Pixel 页不会触发雕刻。画面中的名称与选中边角标记帮助识别行星，Compare、Inspect 或 Pixel 工具开启时隐藏，保持像素分析画面清晰。画面下方的提示会随设计、原貌预览、像素工具和镜头移动更新。

点击 `Run simulation` 后，右侧自动切到 `Simulation`，显示所选行星的位置、速度、距太阳的距离和 `Reference orbit` 对照；`Initial state` 页显示本次运行的初始条件。碰撞列表移至此面板，记录使用行星名称，点击后暂停并跳到碰撞结果、选中幸存行星；回退时间后仍可查看标有 `later in this run` 的书签。已合并的行星会说明其去向，画面不显示它的名称标记，`Focus selected` 暂不可用。碰撞演示显示临时场景的初始条件；退出演示或返回 Design 保留 DIY 项目。返回 Design 后面板也会自动回到设计入口。

本次 Pixel 页改动已在 macOS / Metal 上完成 Release 构建、本地界面检查，以及核心、桌面状态和抗锯齿导出三项自动测试。Windows 界面尚未复测。macOS Clang 构建为 REBOUND 关闭浮点乘加收缩（`-ffp-contract=off`），以避免对称初始条件下 IAS15 积分停滞；该选项只作用于 REBOUND，不改变软件光栅器的编译选项。

## 项目简介

本项目是一个以太阳系为交互场景的 CPU 软件光栅化与抗锯齿分析工具。项目使用 C++ 实现从三维场景到最终图像的关键渲染步骤，以太阳和八大行星构成的动态场景展示变换、投影、纹理、光照、遮挡与采样过程。

太阳系既是可操作的科普展示场景，也是渲染算法的实验对象。用户可以自由观察行星运动，也可以冻结某个时刻，比较不同采样方法生成的图像，并通过像素显微镜查看一个像素如何经过覆盖判断、深度测试、着色和颜色合成。

项目的重点是让渲染结果及其形成过程同时可见：不仅展示“哪种方法更平滑”，还通过真实样本数据和运行统计解释“为什么改善，以及付出了多少计算与存储成本”。

## 核心功能

### 太阳系探索

- 展示太阳与八大行星，复用球体网格并通过参数表配置外观和运动。
- 支持行星公转、自转、轨道示意、暂停、继续和模拟速度调节。
- 支持自由相机、缩放、行星选择、信息展示与平滑跟随。
- 提供太阳系全景、单行星特写和土星环特写等观察预设。
- 使用教学比例、简化圆轨道和可配置周期，突出天体之间的关系与可见性。
- 太阳采用自发光外观，行星根据太阳位置计算漫反射，并加入少量环境光。

### 渲染分析

探索模式与分析模式共享场景状态、相机和渲染内核。进入分析模式时，系统保存统一的场景快照，确保不同采样方法使用完全相同的几何、材质、相机和模拟时刻。

提供以下渲染配置：

- **单采样**：每个像素使用一个样本，作为画质与性能基线。
- **4× SSAA**：对四个子样本分别计算覆盖、深度、纹理和光照，最后合成为像素颜色。
- **4× MSAA**：保留四个覆盖与深度样本，通常对每个三角形覆盖到的像素执行一次着色，再将颜色写入通过测试的样本。
- **离线高采样参考**：使用 16× SSAA 及必要的更高采样配置生成近似参考图，并检查参考结果的稳定性。

4× SSAA 与 4× MSAA 使用相同的样本位置、边界填充规则、纹理过滤和光照配置。颜色合成在线性颜色空间中完成，再统一转换为显示颜色。

### 像素显微镜

点击行星轮廓、土星环或轨道边缘的像素，可以查看本次渲染生成的真实局部数据：

- 像素内的样本位置与覆盖掩码；
- 样本对应的物体和三角形标识；
- 逐样本深度测试与最终可见性；
- 各样本颜色和最终合成颜色；
- 当前像素发生的着色调用及覆盖测试信息；
- 相机或采样配置变化后的同步更新结果。

详细跟踪仅记录选中像素及其附近小区域。普通渲染只保留必要统计，避免诊断功能显著影响整体性能。

### 对比与实验

- 支持单采样、SSAA 与 MSAA 的同步画面对照和局部放大。
- 使用固定内部渲染分辨率，窗口缩放只影响展示大小。
- 像素放大采用最近邻显示，避免界面插值掩盖原始锯齿。
- 提供行星圆弧轮廓、土星环边缘和远处行星运动等可复现预设。
- 交互界面与批量实验调用同一个渲染入口。
- 支持导出无损 PNG 图像、CSV 数据和场景参数。
- 分别记录渲染内核、阶段计算、图像上传与界面绘制的耗时。

## 软件渲染管线

渲染器的主要数据流如下：

```text
行星参数与统一模拟时间
          ↓
太阳系场景、相机与不可变场景快照
          ↓
模型变换 → 齐次裁剪 → 透视投影 → 视口变换
          ↓
三角形覆盖判断 → 逐样本深度测试 → 透视正确插值
          ↓
纹理采样与光照着色 → 样本颜色合成 → 最终图像
          ↓
交互显示、像素诊断与批量实验
```

基础管线包含共享边填充、近裁剪面穿越、前后遮挡、球面纹理接缝和透视正确纹理插值等检查。物体选择使用专门的标识信息，不从经过合成的显示颜色反推对象。

## 系统架构

项目按场景、渲染、诊断和展示划分模块：

- **场景层**：`SolarSystemScene`、`SimulationClock`、`CameraController`，负责天体参数、统一时间和相机状态，输出 `SceneSnapshot`。
- **渲染层**：`GeometryStage`、`Rasterizer`、`TextureSampler`、`Shader`、`SampleBuffer` 与 `Resolve`，负责生成图像及必要的底层数据。
- **配置层**：`RenderConfig` 统一管理分辨率、采样模式、几何精度和调试开关。
- **诊断层**：`PixelTrace` 与 `RenderStats` 保存局部样本记录、着色次数、覆盖测试和阶段耗时。
- **实验层**：`BenchmarkRunner` 批量回放固定快照与配置，导出图像、数据和参数。
- **界面层**：Dear ImGui 提供场景控制、同步对照、像素显微镜和统计图表，不另行模拟算法结果。

采样策略在一次绘制开始时确定，颜色与深度缓冲区集中管理，避免在底层样本循环中反复进行模式分派。

## 技术方案

- **语言与构建**：C++17、CMake
- **交互界面**：Dear ImGui
- **窗口与显示**：GLFW、Metal
- **目标平台**：macOS
- **渲染方式**：行星、环带与轨道三角形的覆盖、深度和着色均由 CPU 完成；Metal 仅负责结果图像与界面的显示

初版使用较低内部渲染分辨率验证可行性和测量开销，高采样参考图离线生成。实际交互表现以原型测量结果为准。

## 实验设计

### 轮廓质量

在固定的行星与环带特写中比较单采样、4× SSAA 和 4× MSAA，记录统一边缘区域的误差、局部放大图和细节保留情况，分析覆盖采样对圆弧轮廓与细薄几何的影响。

### 运行成本

固定场景快照和采样配置，分别改变内部渲染分辨率或球体网格精度，记录内核与阶段耗时、着色次数和缓冲区内存，分析画质提升对应的计算与存储成本。

### 运动稳定

沿相同时间序列和相机路径观察远处行星与细环带，生成同步对照视频，记录漏采样现象及每帧相对同一时刻参考图的误差。

### 诊断一致性

在遮挡边缘检查样本深度、物体归属和合成颜色，并比较开关详细诊断前后的图像，确认像素显微镜的解释与真实渲染计算一致。

性能测试使用 Release 构建，固定机器、编译参数、线程数和内部渲染分辨率。预热后重复测量，报告中位耗时与 P95；正式计时关闭像素跟踪和叠加层，单方法测量与双画面展示分别统计。

## 场景范围与可选扩展

首版限定不透明几何。土星环使用可从两面观察的不透明环带，轨道示意使用细带三角形，两者均进入相同的深度和采样流程。界面文字与标签独立绘制，不计入软件渲染抗锯齿效果的评价区域。

新加入的沙盒使用无量纲多体引力和碰撞合并，但不承担真实日期星历或精密天文预测。天文资料中的物理参数与用于展示的尺寸、距离分别标注，行星信息参考 NASA 公开资料。

在核心功能稳定后，可按需要扩展 Mipmap、分块并行、SMAA、自动画质调节、真实尺度切换、复杂阴影和光晕。这些扩展不作为基础渲染与采样分析的前置条件。
